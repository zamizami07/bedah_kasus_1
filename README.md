Repositori ini berisi 3 proyek visualisasi data menggunakan Streamlit.

## 📂 Daftar Kasus
1. **Bedah Kasus 1 (Penjualan):** Analisis dataset operasional penjualan (`bedah_kasus_1/app.py`).
2. **Bedah Kasus 2 (Mahasiswa):** Analisis dataset profil mahasiswa (`bedah_kasus_2/app_mahasiswa.py`).
3. **Bedah Kasus 3 (Cuaca):** Analisis dataset pengamatan cuaca (`bedah_kasus_3/app_cuaca.py`).

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repositori ini.
2. Install dependencies: `pip install -r requirements.txt`
3. Jalankan aplikasi, contoh: `streamlit run bedah_kasus_1/app.py`
